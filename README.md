# forward_yahoo_mail
Vistit this server, it will forward the last email from Yahoo email to another email address

Environment:

YAHOO_EMAIL

YAHOO_APP_PASSWORD

FORWARD_TO

BREVO_API_KEY:	Brevo API Key

SENDER:	Email Sender, must verified by Brevo first.

Note: You will need your own domain to send email from Brevo server! Public email address will be rejected!
